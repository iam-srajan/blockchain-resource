### Solidity Practice Tasks

1. **Name Storage**
   Create a contract that stores a person's name using `string`. Add a function to change the name.

2. **Age Storage**
   Create a contract that stores a person's age using `int`. Add a function to update the age.

3. **Wallet Address**
   Create a contract that stores a wallet address. Add a function to set the address.

4. **Student Details**
   Store a student's **name** and **age**. Create one function to set both values.

5. **Student Wallet**
   Store a student's **name** and **wallet address**. Create a function to set both values.

6. **Employee Details**
   Store an employee's **name, salary, and wallet address**. Create a function to set all three values.

7. **Product Details**
   Store a product's **name, price, and seller address**. Create a function to set these values.

8. **Owner Address**
   Create a contract with an `owner` address. Create a function that sets the owner to the address of the person calling the function using `msg.sender`.

9. **Bank Account Details**
   Store an account holder's **name, account number, and wallet address**. Create a function to set all three values.

10. **College Student Record**
    Store a student's **name, roll number, and wallet address** using `string`, `int`, and `address`. Create separate functions to update each value.
